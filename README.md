# Import-Export TT Isle Of Man
A Blender add-on for importing P3D and PTX files from TT Isle Of Man: Ride on the Edge 3. Support for exporting files may be added in a future release.

## Usage
1. Download the latest version of this add-on from the [releases](https://github.com/jmancoder/io-tt-isle-of-man/releases) page and install it. Blender 4.2 and newer is supported.
2. In Blender, click *File->Import->TT Isle of Man (.p3d/.ptx)*.
3. Select the P3D or PTX file you wish to import.
4. Click *Import P3D/PTX*.
