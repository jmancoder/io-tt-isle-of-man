# Import-Export TT Isle Of Man
A Blender add-on for importing P3D files from TT Isle Of Man: Ride on the Edge 3. Support for exporting files and working with PTX files will be added in later versions.

## Usage
1. Download the latest version of this add-on from the [releases](https://github.com/jmancoder/io-tt-isle-of-man/releases) page and install it. Blender 4.2 and newer is supported.
2. In Blender, click *File->Import->TT Isle of Man (.p3d)*.
3. Select the P3D file you wish to import.
4. Click *Import P3D*.
